# Revision 8 Rework Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the Huston Logic site to Revision 8: two offers (Accelerated Websites, AI-Centric System Redesign), a new seven-section Home, a new `/systems` page, reworked Services, How I work, Past work, About and Contact, Rev 8 motion, and no prices or Workflow Review anywhere.

**Architecture:** Same stack and rules as today (AGENTS.md): copy lives in typed modules in `src/content/`, route files compose components, Server Components by default, motion is CSS keyframes released by `InViewOnce` (`data-played`) and gated by `html.js` plus `prefers-reduced-motion`. New reusable sections go in `src/components/hl/`.

**Tech Stack:** Next.js 16 App Router (static export), strict TypeScript, Tailwind v4 tokens (`src/app/hl.css`), Cloudflare Worker for `/api/contact`, Node test runner for the Worker, Playwright + axe, Lighthouse CI.

**Spec:** `docs/website-rev8.md` (the only source of new copy). Layout reference: `design-v3/reference/rev8/mockup-home-{phone,desktop}.dc.html` (reference only; the .md wins). Base copy: the repo as it is now.

## Global Constraints

- Copy is verbatim from `docs/website-rev8.md`. Never invent copy. Unknowns become `[[placeholder]]`.
- No price, rate or dollar amount anywhere in the site source. No AI app named ("your AI app", "by talking").
- No industry named as a target market (client names and industries stay on testimonials and case studies).
- Nothing may suggest the talking system is for health or other protected records.
- Wording sweep (must return nothing in `src worker`): `Workflow Review`, `$750`, `Fix a workflow`, `Things keep slipping`, `small outfits`, `Already on Zoho`, `Zoho partners`. "workflow(s)" only in `testimonials.ts` and `past-work.ts` case-study text. "Zoho" only in `past-work.ts` and `about.ts`.
- Step labels stay in `framework.steps` (`site.ts`); use `fw()` tokens, never type "Scope it" by hand.
- Motion: only `transform`, `opacity`, `stroke-dashoffset` animate; one moment per section, played once; no loops, no scroll-linked motion, no library; reduced motion and no-JS show the end state; CLS 0; the H1 stays the LCP element.
- Images: explicit width/height, lazy, AVIF with WebP fallback (`<picture>`), nothing in the first screen.
- Every commit passes `npm run check`. One commit per task on `feat/rev8-rework`. Never merge, never enable auto-merge.
- Do not touch `.claude/**` hooks/agents/skills/settings or `.github/workflows/**`. Do not lower any threshold. Do not connect the form to `/intake`.

## Review Focus

1. **Old links:** `/contact?topic=workflow` (from old pages, emails, search results) must preselect "An AI system for my business"; `/contact?topic=partner` must show the plain form, not a broken one. A stale form posting `need: "workflow"` must still be accepted by the Worker as `system`. (Tests in Task 2.)
2. **Phone swipe rows** (testimonials, phone screenshots) are scrollable regions: axe `scrollable-region-focusable` fails unless the row is keyboard-focusable with a name. (Task 3, checked by `npm run test:a11y`.)
3. **No-JS / reduced motion:** every new start frame must be scoped `html.js` inside `prefers-reduced-motion: no-preference`; a missed scope leaves a bubble, tick or chip invisible. (Task 7, checked by the end-state script in Task 9.)
4. **Hero CLS on phones:** the new fixed-height phone stage must hold its size before fonts load; cards are absolutely positioned inside it. (Task 3, Lighthouse CLS 0.)
5. **Anchors:** `/#hello`, `/#installing`, `/#why`, `/services#websites`, `/services#care`, `/services#faq` must exist exactly once; the sub-nav must not point at a removed `#workflows`. (Task 9 anchor check.)
